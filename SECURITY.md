# Security Policy

## Supported Versions
We provide security updates for the current active versions of OSE projects.

## Reporting a Vulnerability
We strongly encourage responsible disclosure of security vulnerabilities.

If you discover a security vulnerability in any project under the OSE organization:
1. **Do not** disclose the vulnerability publicly in an open GitHub issue or pull request.
2. Please report the issue privately using **GitHub Security Advisories** on the affected repository, or reach out to the organization maintainers via our community Discord.
3. Include detailed steps to reproduce the vulnerability, including any relevant code samples, screenshots, or logs.

We appreciate your efforts to keep our community and software safe!
